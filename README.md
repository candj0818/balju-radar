# 발주 레이더

월 판매량과 재고로 공장별 발주일과 발주 수량을 계산하는 웹 도구입니다.

- 원본: `balju-radar.html` 한 파일

## 계산 요약

- **예상 판매**: 최근 6개월 가중평균. 중간값의 2배 초과·절반 미만인 달은 경계값으로 보정. 12개월 이상이면 계절성 반영(1년치 50%, 2년치 75%).
- **오늘 재고**: 재고 입력일부터 오늘까지 예상 판매분을 빼서 추정. 7일 넘게 갱신하지 않으면 경고.
- **안전재고**: 확률 계수(95% = 1.65) × 월 판매량 표준편차 × √(리드타임 ÷ 30)
- **발주점**: 리드타임 동안 판매량 + 안전재고
- **공장별 묶음 발주**: 공장에서 가장 급한 제품 날짜에, 다음 발주 주기 전에 필요한 제품을 함께 발주
- **수량 규칙**: MOQ 이상, 주문 배수(기본 5)와 박스 입수를 모두 만족하도록 올림
- **40HC 컨테이너**: 공장마다 따로 적재(기본 64CBM, 26,000kg). 빈 공간은 입고 시점 재고일수가 낮은 제품부터 채워 공장 전체가 고르게 같은 일수를 갖도록(최대 120일치). 마지막 컨테이너가 30% 미만이면 급하지 않은 품목을 다음 발주로 미룸.
